# 项目术语库

跨章节写作、模块改名或出现一物多名时维护术语库；单句润色直接遵循已有正文。

| 英文规范名 | 中文规范名 | 定义 | 易混用写法 | 来源或首次定义 | 备注 |
|---|---|---|---|---|---|
| | | | | | |

“易混用写法”不是全局禁词。同一词在不同语境中可能有独立含义；只纠正具体的语义漂移。

优先检查指标名称、分母与划分、发表方法与内部变体的身份、理论对象，以及图表中的简称。

## 改名时

1. 在授权范围内定位旧名，区分正文、表格、图中文字、标签和参考文献。
2. 修改同一概念对应的出现位置；不改同名但不同语义的对象。
3. 保持数值与事实身份不变。涉及基线身份变化时，同步说明其比较设置。
4. 引用键和标签通常不需要随显示名称改动；确需改动时同步更新使用位置。
5. 查看相关 diff，必要时编译与查看受影响的图表。

不为了改名扫描未经授权的历史目录，也不重新生成实验结果。
