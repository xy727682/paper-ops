# 从文献语料到论文表达

## 定锚点

从当前对话和稿件确定：写哪一部分、面向哪个领域与读者、目标语言与篇幅、已有数据与文献、哪些结论已经成立。信息已明确时不重复询问。

## 收集与阅读

先使用用户授权的项目文献和已有参考文献表，再按需要检索公开原文。选择能覆盖主题基础、最近邻工作和目标 venue 写法的材料；规模服从任务，不为凑固定数量扩大检索。

本技能不附带文献库，也不假定特定 Zotero 索引存在。用户指定只读某个目录时，不越过该范围查找私人 PDF。缺少材料时先推进已获证据支持的部分，列明需要的文献。

建议台账：

| 文献 | 版本与出处 | 来源链接或授权本地路径 | 检索式 | 阅读层级 | 用途 |
|---|---|---|---|---|---|
| | | | | 全文／摘要／仅检索 | |

检索到记录不等于读过全文，预印本与正式版的结论、年份和页码可能不同。论文描述以实际阅读的版本为准。

## 建立术语库

从草稿和相关文献提取反复出现的概念、方法、设置和指标，记录定义及来源。优先保留作者已确定的名称；领域术语不因本项目偏好改变含义。

名词短语频率可以帮助发现候选术语，但不能代替语义判断。不将语言统计视为写作质量评分。

## 学习修辞功能

关注四类常见动作：如何开场提出问题、如何定位最近邻方法、如何陈述实验比较、如何交代适用条件。记录句子的功能与结构，以及其出处；不要整句照搬。

| 修辞动作 | 出处位置 | 结构笔记 | 本文需要的证据 |
|---|---|---|---|
| 结果比较 | | 方法 A 在任务 D 的指标 M 上相对 B 的变化 | 对应结果表及比较协议 |
| 方法定位 | | 已有路线的共同点、具体缺口与本文处理方式 | 相关原文及自己的方法定义 |

以上是结构示意，不是真实文献摘录。句式库应随项目维护，仅收录有出处的笔记；引用或摘录须遵循原材料的使用条件。

相关工作可按共识、差异、局限和切入点组织，但必须由真实文献支持。无法从文献推出的研究空白，不通过更强的措辞制造。

## 起草与回读

从本文概念、研究问题与证据出发选择表达。回读时先看论证，再看语言。对同类型文献作比较时，检查段落功能、术语和信息密度，不机械模仿段长、词频或连接词数量。
