# 第 4 层：验收范式

核心：**编译通过 ≠ 完成。完成 = 连续两轮渲染审查无新问题。**


## R4.1 验收循环

每轮修改后：

1. 编译（论文：pdflatex→bibtex→pdflatex×2；`??` 引用零容忍）
2. pdftoppm 渲染逐页 PNG
3. 逐页视觉审查（R4.3 七个维度）
4. 问题清单 → 修复 → 回到 1
5. 连续两轮无新问题 → 完成

## R4.2 审查自证

视觉审查必须产出证据：转录图中若干文字/数字、指出具体位置的具体问题。"看起来没问题"式放行不算审查。

## R4.3 七个审查维度（每页都过）

1. 乱码/转义残留（rnrn、`\subsection` 字面残留、编码乱码）
2. 字号过小/不一致
3. 对齐与溢出（双栏长公式、表格行内换行、超宽）
4. 浮动体位置（图飘到标题前/结论后、浮动体打断 Limitations 等关键节）
5. caption-图内一致性（接第 3 层）
6. 页眉页脚污染（hyperref 染色、模板元素丢失）
7. 异常空白（\clearpage 造成半页空、分页拆开评分与图）

## R4.4 脚本的地位

- 脚本（check_tex、坏词扫描、占位扫描）只报异常，裁决在人/agent
- 误报必须记录，误报模式喂回脚本改进
- 严禁为了过脚本改坏正确的文字；否定句、引用、标题里的命中先判语境

## R4.5 回归核对

每轮审查先确认上轮已修问题未复活，再找新问题。回归失败优先于新发现。

## 完成判据

- 连续两轮渲染审查无新问题
- 审查记录表：每轮 已修/未修/新发现/误报 四列齐全
- 上轮问题回归通过
